# 03 — Roadmap (план и прогресс)

**Главный файл.** Что сделано (чек-лист) и куда двигаемся (фазы). Обновлять по ходу.
Строим **снизу вверх**: не переходим к следующей фазе, пока предыдущая не играбельна.
Концепцию на полпути не меняем.

Цель этапа: **собрать Этап 1 «Лес» ЦЕЛИКОМ** — карта с узлами и выбором пути,
персистентная армия, формирование отрядов, прокачка (таланты/лут), бои, события,
финал-граница города.

## Концепция (кратко, подробно — «01» и «04»)
- Рогалик в духе Slay the Spire: карта-граф, идёшь снизу вверх, выбираешь путь.
- **Персистентный отряд** зомби: гибнут, лечатся, поднимаются из трупов, качаются.
- **Биомасса** — опыт-валюта (копится за бои), тратится на таланты и апгрейд зомби.
- **Слоты/отряды:** до 5 отрядов × до 5 слотов; вес зомби 1/2/3 (обычный/бегун/толстяк).
- В бою выставляешь готовые отряды (целиком, по разу); без таймера.

## ⏭️ ПЛАН СБОРКИ ЭТАПА ЛЕС

### Фаза 1 — Довести один бой (плейтест-баланс)
Сделать текущий бой честным и приятным на 2–4 минуты. Это шаблон боя.
- [ ] Прогнать бой, подкрутить числа (`.tres`, `Config`): не «всегда вин/слив».
- [ ] Убрать таймер-рассвет из условия поражения (по «02»: бой до победы/гибели отряда).
- [ ] Проверить: дом достроен (все стены), проём проходим, стрельба через окна/дверь.
- Не двигаться дальше, пока бой не станет играбельным.

### Фаза 2 — Карта леса с захардкоженными точками (КАРКАС)
Сначала собираем скелет «карта ↔ бой», без экономики. Армию/отряды/награды
навешиваем позже (Фаза 3). Цель — ходить по карте и проваливаться в события.

**Как устроена карта (принцип Slay the Spire):**
- Узлы разложены по горизонтальным СЛОЯМ снизу вверх.
- Внизу 1 узел (старт), наверху 1 узел (город-финал), между — слои по 2-3 узла.
- Связи ТОЛЬКО между соседними слоями. Идёшь вверх, на развилке выбираешь узел.
- **Тип узла ВИДЕН заранее по иконке** (бой / событие / лагерь / находка / город) —
  выбор пути осмысленный, ты знаешь, во что идёшь.
- Пройден узел → доступны те, куда из него ведут связи; остальные гаснут.

**Типы узлов (иконки на карте):**
- **Бой** — драка (движок готов).
- **Событие (вопрос)** — экран с текстом ситуации и выбором 2-3 вариантов; разные
  исходы (лут / риск / потеря / иногда приводит к бою). Это НЕ пустой бой — это
  осмысленный выбор, ради него карта не сводится к «бой за боем».
- **Лагерь** — восстановление отряда (лечение).
- **Находка** — лут / биомасса.
- **Город** — финал этапа.

**Реализация:**
- [ ] Данные карты — захардкоженный список узлов: `{ id, тип, x, y, связи:[id,...] }`.
- [ ] Сцена карты (`forest_map.tscn`): кружок+иконка на узел, линии на связи.
      Доступные кликабельны, недоступные погашены. Иконка = тип.
- [ ] Клик по узлу → грузим сцену этого типа (`change_scene_to_packed`), запоминаем
      текущий узел. Возврат → снова карта, открываются следующие узлы.
- [ ] **Сцена события-вопроса** (`event.tscn`): текст ситуации + 2-3 кнопки выбора,
      каждый вариант ведёт к исходу (лут / потеря / переход в бой). Захардкожено
      по одному событию на узел.
- [ ] Autoload `GameState` (минимальный): текущий узел, пройденный путь. Живёт между
      сценами. (Армия/биомасса — Фаза 3.)
- [ ] Наполняем узлы ПО ОЧЕРЕДИ, захардкоженно: свой бой / своё событие / свой лагерь.
- [ ] Арт карты: фон леса + иконки узлов.

Итог фазы: ходишь по карте леса, ВИДИШЬ типы узлов, выбираешь путь, попадаешь в
бои и события-вопросы, доходишь до города. Экономики и отрядов ещё нет — это каркас,
но уже НЕ «чистые бои» (события делают путь осмысленным).

### Фаза 3 — Армия, отряды, экономика, награды, прокачка
Навешиваем на каркас рогалик-начинку. Здесь появляется персистентный отряд.
- [ ] **Персистентная армия:** зомби — записи в `GameState` (тип/HP/лут), живут между
      боями. В бою используются её зомби, а не разовые.
- [ ] **Формирование отрядов** (экран между боями): распределяешь армию по отрядам
      (до 5 отрядов × до 5 слотов; вес 1/2/3).
- [ ] **Переделать бой под отряды:** панель боя = сформированные отряды; выбор отряда →
      клик в тень → весь отряд появляется (по разу). Заменяет старый спавн по пачкам.
- [ ] Старт забега: экран набора стартовой армии в пределах слотов.
- [ ] **Биомасса за бой:** формула от числа врагов и скольких убил. Копится в GameState.
- [ ] **Экран награды после боя (выбор):** пополнить отряд / вылечить (фикс. хил) /
      израсходовать трупы на биомассу / лут. Трупы = убитые (не сбежавшие).
- [ ] **Лечение/подъём:** трупы врагов → поднять зомби или вылечить; жертва своего
      зомби → лечение других (между боями).
- [ ] **Древо талантов** (4 ветки: обычные/бегуны/толстяки/общие). Покупка за биомассу
      по нарастающей цене (10→20→…). Только на забег. Общие таланты: +слоты/+отряды/
      +% биомассы/апгрейды. Апгрейд зомби (обычный→бегун→толстяк) открывается талантом.
- [ ] **Лут (3 вида):** модификатор на особь (зашить рот, жестянки-броня…),
      талисман на отряд, базовый групповой баф (за нахождение в отряде).

### Фаза 4 — События (узлы без боя)
- [ ] Узлы-события с выбором (см. список ниже).
- [ ] Лагерь/стоянка: лечение/апгрейд армии.
- [ ] Логово: покупка особого типа за биомассу.
- [ ] Реализовать риск/награду (капкан ранит, аномалия и т.д.).

### Фаза 5 — Финал этапа (граница города)
- [ ] Узел-босс наверху карты: усиленный бой (больше/сильнее защитников,
      возможно спец-механики). Победа → концовка этапа (Город — потом).

### Фаза 6 — Полировка и мета (после играбельного этапа)
- [ ] Баланс всей петли (старт → босс), длина этапа (сколько узлов).
- [ ] Сохранение забега (JSON).
- [ ] Отложенные фишки: таймер-рассвет, заря по краям, изометрия, анимация спрайтов.

## Типы узлов Этапа Лес
старт · бой · лагерь (лечение/апгрейд) · находка (биомасса/лут) · событие · логово ·
граница города (финал).

## События (пул, выбираем реализацию в Фазе 4)
- Брошенный лагерь охотников — лут/биомасса, риск: капкан ранит зомби.
- Свежий труп — бесплатно поднять зомби (слабого).
- Логово — заплати биомассой → особый тип зомби.
- Аномалия/болото — провести армию через (риск) или в обход.
- Раненый зверь — мини-бой → приручить зверя-юнита.
- Развилка-дилемма — быстрый опасный путь vs долгий безопасный.
- Ловушка людей — засада (внезапный бой), но щедрый лут.
- Костёр/ритуал — пожертвовать зомби → усилить остальных.

---

## Правила разработки (не забывать)
1. Снизу вверх: не переходить к след. фазе, пока текущая не играется.
2. ИИ правит `.gd` (и `.tscn` по согласованию). Bake навигации / расстановку узлов
   мышью / регистрацию autoload делает разработчик.
3. Числа — в `Config`/`.tres`, не хардкодить вразброс.
4. Читаемость: тип/роль различаются силуэтом и цветным кантом («05»).
5. Коммитить часто, маленькими шагами. Диск держать свободным (>5 ГБ).

## Отложено (сознательно)
- Таймер-рассвет и заря по краям (вернём как фишку боя).
- Изометрия, анимация спрайтов (сейчас статичные PNG + боббинг).
- Спец-типы зомби (взрывной/прыгун/невидимка/плевок) — после базовых трёх.
- Мета-прогресс между забегами — после играбельного этапа.
- Реорг папок под целевую структуру («06»).

## Известные засады (из опыта)
- Копии одной сцены делят начинку → правый клик → Make Local.
- ColorRect от угла, CollisionShape2D от центра → ColorRect.position = -size/2.
- Узкий проём навигация «зарастает» → вход 80–100 px, agent_radius ≈ 25.
- Навигации нужен кадр (`await physics_frame`), иначе зомби стоят.
- После правки стен — Bake NavigationPolygon заново.
- Y-Sort не включать на узле с Control-нодами.
- ИИ может ломать .tscn — коммитить до правок, откат `git checkout`.
