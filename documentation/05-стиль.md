# 05 — Стиль (визуал)

> **Заметка (актуализация):** визуальный стиль и палитра — актуальны и движко-независимы.
> Техническая часть (стек, архитектура, запуск) ПЕРЕЕХАЛА в «06 — Техника и Godot»:
> проект теперь на Godot 4.4, не на Phaser. Ниже техчасть оставлена как исторический

## Визуальный стиль

### Ориентир: Project Zomboid
Северная звезда стиля — **Project Zomboid**: приглушённый «грязный» survival-horror,
вид сверху (позже изометрия), утилитарная читаемость важнее фотореализма. Берём
**тон и подход к подаче** — тусклый свет, землистая палитра, ощущение осаждённого
дома. Ассеты Project Zomboid (и любых игр) не копируем: весь арт оригинальный,
опираемся только на общее настроение.

### Драматический слой: «ночь → рассвет»
Поверх приглушённой базы — один яркий приём: **защитники в тёплом круге света
посреди тьмы**, орда лезет из чёрных краёв, а к концу таймера по краям арены
**разгорается заря** (это же и условие проигрыша). Это фирменный кадр игры;
всё остальное держим тихим и тёмным.

### Палитра
Интерфейс — тёмная сине-графитовая ночь с янтарным акцентом:
- фон `#0b0e14`, панели `#141a26`, границы `#26314a`
- текст `#e7ecf3`, вторичный `#8a93a3`
- акцент / рассвет / выбор `#ff8a3d`

Цвета-роли юнитов (насыщенные ради читаемости, не смешиваются с фоном):
- зомби `#86c541`, стрелок `#5bc8ff` (голубой), ближний `#ffb454` (янтарь)
- HP: полное `#6ee06e`, среднее `#ffd24a`, низкое `#ff5a5a`

При переходе на спрайты палитра арены сдвигается к «земле» Project Zomboid
(тусклые зелёно-болотные, бурые, серо-бетонные), но цвета-роли остаются яркими.

### Правило читаемости (жёсткое)
Даже в тусклой сцене силуэт и цвет обязаны за долю секунды отвечать на вопросы:
человек или зомби? стрелок или ближний? какой тип зомби? Тип различается силуэтом
и цветовым кантом, а не только оттенком.

### План визуала
1. Сейчас — плейсхолдер-кружки. Менять не срочно.
2. Спрайты — вид сверху, 32–40 px, 2 кадра ходьбы + 1 кадр атаки, свой атлас на тип.
3. Изометрия — позже, тот же контент в изо-проекции.

### «Сок» (juice), дозированно
Вспышка выстрела, дуга ножа, брызги укуса — уже есть. Позже: кровь-декали, лёгкая
тряска экрана на взрывах, пульс света на боссе. Не перегружать: избыток эффектов
делает картинку «шумной».

### HUD
Тёмные панели; шрифты Oswald (крупные цифры и таймер) + JetBrains Mono (метки и
данные). Сдержанно, без лишнего декора. Новые экраны (награда, карта кампании)
держим в этой же системе.

## Техника

### Стек
- **Phaser 3** — игровой движок (рендер, ввод, цикл, масштаб).
- **Vite** — dev-сервер с горячей перезагрузкой и сборка в статику.
- Чистый JavaScript, ES-модули. Интерфейс — обычный DOM/CSS вокруг канваса.

### Запуск
```bash
npm install
npm run dev      # локальный сервер, обычно http://localhost:5173
npm run build    # сборка в папку dist/
```

### Архитектура (главный принцип)
**Игровая логика отделена от движка.** Phaser используется только в слое сцены;
конфиг, состояние и системы (ИИ, бой, спавн, поиск целей) — чистый JS, не зависящий
от Phaser. Это упрощает тесты, правки баланса и возможный перенос.

- Весь **баланс** собран в одном месте (объект конфигурации) — числа не разбросаны по коду.
- **Новые типы зомби** добавляются как данные (набор полей), а не отдельными ветками
  `if` по всему коду.
- **Перки и реликвии** реализуются как **модификаторы**: не патчат код напрямую,
  а меняют общий объект бонусов забега, который читают системы при расчётах.

### Публикация
- **itch.io** — основная площадка для HTML5-игр: собрать `npm run build`,
  заархивировать содержимое `dist/`, залить как веб-игру. Тут живые игроки и фидбек.
- **GitHub Pages** — быстрый веб-деплой для ссылки на тест.

### Ограничение по сохранениям
Сохранение забега — обычный JSON в браузере (localStorage) на реальном хостинге.
Внутри артефактов Claude localStorage не работает — там состояние держим в памяти.
