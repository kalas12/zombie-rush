# База знаний — «Осада на рассвете» (zombie-rush)

Reverse tower-defense на **Godot 4.4** с рогалик-структурой в духе Slay the Spire.
Вместо колоды карт — **живой персистентный отряд зомби**: растишь, лечишь, модишь,
теряешь. Ведёшь армию через карту леса к границе города.

## Кратко о концепции
- **Персистентный отряд** — зомби гибнут/лечатся/поднимаются из трупов/качаются.
- **Биомасса** — опыт-валюта (за бои), тратится на таланты и апгрейд зомби.
- **Слоты/отряды** — до 5 отрядов × 5 слотов; вес зомби 1/2/3 (обычный/бегун/толстяк).
- **Карта леса** — узлы с иконками (бой/событие/лагерь/находка/город), выбор пути
  снизу вверх, финал — граница города.
- **Бой** — выставляешь готовые отряды в тень вокруг дома, целиком, по разу. Без таймера.

## Текущий фокус
Собрать **Этап 1 «Лес» целиком**. Порядок: довести бой → каркас карты с точками и
событиями → армия/отряды/экономика → события → финал-город. См. «03».
