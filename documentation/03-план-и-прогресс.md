## Общая концепция кампании

Игра делится на **этапы-локации**. Каждый этап — **карта-граф** в стиле Slay the
Spire: узлы и развилки, игрок ведёт орду снизу вверх, на каждом шаге выбирая путь.
Наверху карты — **узел-босс**, победа над ним = переход на следующий этап.

- **Этап 1 — Лес.** Делаем сейчас. Узлы: бои, события, стоянки, торговец.
  Финал наверху карты — **МОСТ**: тяжёлый бой, ворота в город.
- **Этап 2 — Город.** Потом. Своя тема узлов и боёв, свой босс.

### Типы узлов Этапа 1 (Лес)
старт · бой · событие · стоянка (отдых) · торговец · мост (босс).

### Прогресс между боями (сбор билда)
- **Награда за бой** — выбор 1 из 3 (перк / реликвия / новый тип зомби / ресурс).
- **Восстановление орды** — стоянки; поедание трупов людей (реликвии).
- **Пополнение войска** — лимит зомби на карте, стартовый резерв, дешевле спавн.
- **Новые типы зомби** — открываются как награда/покупка.
- **Апгрейд отряда** — усиление типов через перки/реликвии.

Числа перков/реликвий/типов — в «04 — Контент».

## ✅ СДЕЛАНО (на 2026-09-01)

### Фундамент боя — Шаг A
- [x] Дом: коробка из стен по центру арены, проём-вход.
- [x] Навигация: `NavigationRegion2D` + `NavigationAgent2D`, зомби обходят стены и
      заходят в дом через проём (`await physics_frame`, `get_next_path_position`,
      `is_navigation_finished`).
- [x] Зомби (`zombie.gd`): идут к **ближайшему** живому защитнику (пере-выбор раз в
      0.5 с), укус, HP, смерть.
- [x] Защитники (`human.gd`): 2 стрелка + 2 ближних. Стрелок стоит и бьёт по
      видимости; при перезарядке (обойма кончилась) отходит к своему посту.
      Ближник выходит навстречу зомби и бьёт вплотную. Все ограничены интерьером
      дома (не влипают в стены).
- [x] **Паника**: HP < 30 % → защитник бросает бой, бежит через дверь к краю поля,
      за краем исчезает. Зомби продолжают его преследовать как ближайшую цель.
- [x] Линия видимости: `PhysicsRayQueryParameters2D` — стрелок не бьёт сквозь
      глухую стену и закрытую дверь.
- [x] **Ломаемая дверь** (`door.gd`): HP, зомби бьют по ней вместо человека;
      сломалась → спрайт `door_broken`, коллизия выключается, проход открыт.
- [x] **Окно-бойница**: слой коллизий 2 — зомби не проходят, пули/видимость
      проходят.
- [x] Таймер-рассвет 6:00; **победа** (все защитники убиты/сбежали) / **поражение**
      (рассвет / кончились зомби). **R** — заново.
- [x] HUD кодом: таймер, счётчики, подсказки, панель спавна.
- [x] «Сок» (`Fx.burst`): брызги при укусе, вспышка+искра выстрела, разлёт при
      смерти зомби.
- [x] Арт: стены (`wall_h/v`), дверь, окно, деревья по краям, тайлы земли 6×6,
      спрайты юнитов.

### Типы зомби данными — Шаг B

## Отложено (сознательно)

| что | почему можно ждать |
|---|---|
| Реорг папок (`scripts/units`, `scripts/systems`, `arena`→`battle`) | косметика, игре ничего не даёт |
| Y-Sort (глубина по Y) | сломался на корне; нужен отдельный узел `World` только для игровых объектов, фон вне сортировки |
| Пул объектов (зомби/эффекты) | при ~36 юнитах не нужно; важно для большой орды |
| `set_physics_process(false)` вне экрана | нужно при большой карте (Шаг C+) |
| `flip_h` (спрайт по движению) | убран — юниты резко разворачивались, выглядело плохо |
| Экономика биомассы в бою | это механика рогалика (Шаг C+), в одиночном бою — простые пачки по типам |

## Правила разработки (не забывать)
1. Снизу вверх: не переходить к след. шагу, пока текущий не играется.
2. ИИ правит `.gd` и `.tscn` (в этом проекте — вместе с разработчиком). Bake
   навигации и расстановку узлов мышью делает разработчик.
3. Числа — в `Config` и `.tres`, не хардкодить вразброс.
4. Читаемость: тип/роль различаются силуэтом и цветным кантом (из «05»).
5. Коммитить часто, маленькими шагами.
6. Держать свободным диск (>5 ГБ) — иначе инструменты виснут.

## Идеи на потом (не терять)
- Изометрия (тот же контент в изо-проекции).
- Спрайты: 2 кадра ходьбы + 1 атаки на тип; сейчас статичные PNG — ок для MVP.
- Лёгкий «боббинг» юнитов (колебание по Y синусом) — дёшево оживляет.
- Заря по краям арены к концу таймера — фирменный кадр из «05».
- Новые типы людей: `civilian` (много биомассы, паникует), `shotgunner` (арт уже в
  `assets/units/`) — просто новые `HumanType` `.tres`.
- `log` / `rock` — заготовки для боя «завал/засека».

## Известные засады (из опыта)
- Копии одной сцены делят начинку — правый клик → **Make Local**, чтобы отвязать.
- `ColorRect` считается от угла, `CollisionShape2D` — от центра: чтобы совпали,
  `ColorRect.position = -size/2`.
- Узкий проём навигация «зарастает» — вход делать 80–100 px, `agent_radius` ≈ 25.
- Навигации нужен кадр (`await physics_frame`), иначе зомби стоят.
- После правки стен — **Bake NavigationPolygon** заново.
- Y-Sort нельзя включать на узле, где есть `Control`-ноды (ломает отрисовку).
- «Unrecognized UID» / рассинхрон кэша — **Project → Reload Current Project** или
  удалить `.godot/` (он в `.gitignore`).
